## Getting Started

### Prerequisites

- **Windows** operating system
- **Visual Studio** (2015 or newer) with the **.NET desktop development** workload

### Run the app

1. **Clone the repository**
   ```bash
   git clone https://github.com/ahmedhussienaboomar-tech/Image-Processing-Project.git
   ```

2. **Open the solution**
   Double-click `WindowsFormsApplication7.sln` to open it in Visual Studio.

3. **Run**
   Press `F5` (or click **Start**) to build and run the application.
